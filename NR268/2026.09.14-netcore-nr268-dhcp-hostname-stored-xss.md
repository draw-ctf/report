# Netcore NR268 Stored Cross-Site Scripting via DHCP Hostname Fields

**Vendor:** Netcore  
**Product:** NR268 Router  
**Affected Version:** NR268-V1.7.121109.bin  
**Vulnerability Type:** Stored Cross-Site Scripting (XSS) (CWE-79)  
**Credits:** Zhou Ao, Zhang Yu, Yang Yang, Liu Xin @Nebusec

## Summary

DHCP hostnames survive storage with quotes and markup intact, are serialized unescaped by `filter_hosts_dump.cgi` and `arp_bind_list_show.cgi`, and are consumed by `eval('('+data+')')` plus HTML table rendering. An unauthenticated LAN client can pick a malicious hostname such as `</td><svg/onload=alert(1)>` that is later written into administrator views with `innerHTML`. When an operator opens the system-status or ARP-bind pages, that stored hostname executes in the router origin without any web-management authentication from the LAN client.

## Technical Details

`write_lease` emits `client-hostname "%s"` / `hostname "%s"` after rejecting only bytes below `0x21` or equal to `0x7f`. Quotes, angle brackets, slashes, and JavaScript punctuation therefore survive. The switch host module later serializes the stored name with raw `%s`. The CGI layer never escapes quotes, so a quote-bearing hostname can break the string that `eval` parses. Payloads that avoid quotes still survive into HTML sinks such as `$("#host_con_info").html(row_str)`.

### Affected Endpoint

- URL: `/router/filter_hosts_dump.cgi`, `/router/arp_bind_list_show.cgi`
- Parameters: stored `host_name` serialized with `%s`
- Method: POST
- Authentication: LAN DHCP hostname needs no web auth; list/show routes use HTTP Basic authentication

## Proof of Concept

From a LAN client, request a DHCP lease with hostname:

```text
</td><svg/onload=alert(1)>
```

Then, as administrator:

```bash
curl -s -u admin:admin -X POST "http://192.168.1.1/router/filter_hosts_dump.cgi" \
  -d "noneed=noneed"

curl -s -u admin:admin -X POST "http://192.168.1.1/router/arp_bind_list_show.cgi" \
  -d "noneed=noneed"
```

A quote-bearing hostname that breaks the `eval` parser:

```text
","x":(globalThis.p=1),"y":"
```

Open the system-status LAN view or the ARP-bind view. Table cells are built as `'<td><div style="font-size:12px;">' + host_name + '</div></td>'` and injected with `innerHTML`.

### Outcome

Both dump/list responses contain the unescaped hostname. The administrator page executes the stored SVG/`eval` payload in the router origin.

## Impact

- **Confidentiality:** High
- **Integrity:** High
- **Availability:** Low

An unauthenticated LAN-side attacker can persist JavaScript that executes in the administrator browser when host-status or ARP pages are viewed.
