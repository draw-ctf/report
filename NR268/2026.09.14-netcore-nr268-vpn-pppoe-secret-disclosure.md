# Netcore NR268 Cleartext Disclosure of Stored VPN and PPPoE Secrets

**Vendor:** Netcore  
**Product:** NR268 Router  
**Affected Version:** NR268-V1.7.121109.bin  
**Vulnerability Type:** Cleartext Storage / Information Disclosure (CWE-312 / CWE-200)  
**Credits:** Zhou Ao, Zhang Yu, Yang Yang, Liu Xin @Nebusec

## Summary

The PPTP server user list, PPTP client profile dump, and PPPoE account dump CGI handlers serialize stored passwords back into JSON responses. The PPPoE dump path also writes those credentials into `/tmp/pppoe_account.file` for browser export. Any party with a management session can recover reusable VPN and PPPoE credentials, including PPTP server user passwords, PPTP client `pass` fields, and PPPoE account passwords, by posting `noneed=noneed` to the corresponding show/dump routes.

## Technical Details

The affected handlers treat stored password fields as readable values and append them verbatim into JSON bodies. The frontend then repopulates management form fields from those returned values. For PPPoE account management it renders plaintext passwords in the table, in the edit form, and through the export file at `/tmp/pppoe_account.file`.

### Affected Endpoint

- URL: `/router/pptpd_user_show.cgi`, `/router/pptp_client_config_show.cgi`, `/router/pppoe_server_account_dump.cgi`
- Parameters: `noneed=noneed`
- Method: POST
- Authentication: HTTP Basic authentication

## Proof of Concept

```bash
curl -s -u admin:admin -X POST "http://192.168.1.1/router/pptpd_user_show.cgi" \
  -d "noneed=noneed"

curl -s -u admin:admin -X POST "http://192.168.1.1/router/pptp_client_config_show.cgi" \
  -d "noneed=noneed"

curl -s -u admin:admin -X POST "http://192.168.1.1/router/pppoe_server_account_dump.cgi" \
  -d "noneed=noneed"
```

The PPPoE management page also exposes `./pppoe_account.file` as a plaintext export.

### Outcome

HTTP 200 JSON bodies contain stored VPN and PPPoE credentials in cleartext, including fields such as `password`, `pass`, and `passwordN`.

## Impact

- **Confidentiality:** High – PPTP server passwords, PPTP client `pass` fields, and PPPoE account passwords are exposed.
- **Integrity:** Low
- **Availability:** Low

Recovered secrets can be reused outside the router for upstream VPN and ISP PPPoE authentication.
