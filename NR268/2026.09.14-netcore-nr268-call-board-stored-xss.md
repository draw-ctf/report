# Stored Cross-Site Scripting in L7 Call-Board List Views

- Published: 2026-09-14
- Supplier: Netcore
- Product: NR268
- Affected version: NR268-V1.7.121109.bin
- Vulnerability type: Stored Cross-Site Scripting (XSS)
- Contributors: Zhou Ao, Yin Luxing, Jiang Yuxuan, Liu Xin, @Nebusec

## Summary
Call-board user fields are stored and later rendered into list views that the admin UI eval-parses without encoding.

## Affected Component / Code Path
- `/router/l7_call_board_user_set.cgi`
- `/router/l7_call_board_user_list.cgi`

## Technical Details
l7_call_board_user_set.cgi stores attacker-controlled fields. l7_call_board_user_list.cgi returns them to the administrator UI, which executes them through eval/HTML sinks.

## Verification
- Tested firmware: `NR268-V1.7.121109.bin`
- Authentication: Write: authenticated management user. Trigger: administrator viewing the list.
- Replace `DEVICE`, `USER`, and `PASS` with a lab device and a management account.

```
curl -sS -u USER:PASS -X POST -d 'user=test' http://DEVICE/router/l7_call_board_user_set.cgi
curl -sS -u USER:PASS -X POST -d 'noneed=noneed' http://DEVICE/router/l7_call_board_user_list.cgi
```

Expected result: The list response contains the stored field unescaped, and the admin UI eval-parses it.

These steps are for vendor/CNA verification on a lab device. They are not a full exploit chain.

## Impact
A later administrator visit to the call-board list runs attacker-controlled script in the router origin.
