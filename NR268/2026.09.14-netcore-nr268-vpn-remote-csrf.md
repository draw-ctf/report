# Cross-Site Request Forgery on VPN and Remote-Access Write Endpoints

- Published: 2026-09-14
- Supplier: Netcore
- Product: NR268
- Affected version: NR268-V1.7.121109.bin
- Vulnerability type: Cross-Site Request Forgery (CSRF)
- Contributors: Zhou Ao, Yin Luxing, Jiang Yuxuan, Liu Xin, @Nebusec

## Summary
VPN and remote-access write endpoints accept POSTs after Basic authentication only, with no Origin, Referer, or nonce check.

## Affected Component / Code Path
- `/router/WebRemotePortSet.cgi`
- `/router/pptpd_adduser_set.cgi`
- `/router/pptp_client_add.cgi`
- `/router/pppoe_server_account_import.cgi`

## Technical Details
WebRemotePortSet.cgi, pptpd_adduser_set.cgi, pptp_client_add.cgi, and pppoe_server_account_import.cgi change remote-access state from ambient browser credentials.

## Verification
- Tested firmware: `NR268-V1.7.121109.bin`
- Authentication: Victim browser with cached management Basic authentication
- Replace `DEVICE`, `USER`, and `PASS` with a lab device and a management account.

```
curl -sS -u USER:PASS -X POST -d 'port=8080' http://DEVICE/router/WebRemotePortSet.cgi
```

Expected result: The write is accepted without Origin/Referer/token validation.

These steps are for vendor/CNA verification on a lab device. They are not a full exploit chain.

## Impact
A logged-in administrator visiting a hostile page can have VPN users, PPTP clients, PPPoE accounts, or the remote management port changed.
