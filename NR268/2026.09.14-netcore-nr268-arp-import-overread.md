# Stack Buffer Over-read in the ARP Filter Upload Import Handler

- Published: 2026-09-14
- Supplier: Netcore
- Product: NR268
- Affected version: NR268-V1.7.121109.bin
- Vulnerability type: Out-of-Bounds Read
- Contributors: Zhou Ao, Yin Luxing, Jiang Yuxuan, Liu Xin, @Nebusec

## Summary
The ARP filter import handler uses string APIs on an upload buffer that is not guaranteed to be terminated, causing a stack over-read.

## Affected Component / Code Path
- `/router/filter_arp_put_file.cgi`

## Technical Details
filter_arp_put_file.cgi imports uploaded ARP-filter data with string operations that read past the intended buffer when termination is missing.

## Verification
- Tested firmware: `NR268-V1.7.121109.bin`
- Authentication: HTTP Basic authentication, valid management account
- Replace `DEVICE`, `USER`, and `PASS` with a lab device and a management account.

```
curl -sS -u USER:PASS -F 'put_file=@arp.bin' http://DEVICE/router/filter_arp_put_file.cgi
```

Expected result: An unterminated or short upload triggers over-read behavior in the import handler.

These steps are for vendor/CNA verification on a lab device. They are not a full exploit chain.

## Impact
A crafted upload can crash the CGI or leak adjacent stack memory.
