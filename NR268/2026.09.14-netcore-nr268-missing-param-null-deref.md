# NULL Pointer Dereference from Missing Form-Parameter Checks

- Published: 2026-09-14
- Supplier: Netcore
- Product: NR268
- Affected version: NR268-V1.7.121109.bin
- Vulnerability type: NULL Pointer Dereference
- Contributors: Zhou Ao, Yin Luxing, Jiang Yuxuan, Liu Xin, @Nebusec

## Summary
Some setter handlers pass get_form_value() results to atoi or other consumers without checking for a missing parameter, causing a NULL dereference.

## Affected Component / Code Path
- `firewall/ACL/QoS setter CGI handlers`

## Technical Details
When an expected form field is omitted, the handler still consumes the NULL pointer and the CGI crashes.

## Verification
- Tested firmware: `NR268-V1.7.121109.bin`
- Authentication: HTTP Basic authentication, valid management account
- Replace `DEVICE`, `USER`, and `PASS` with a lab device and a management account.

```
curl -sS -u USER:PASS -X POST -d '' http://DEVICE/router/<affected_setter>.cgi
```

Expected result: The CGI crashes or returns an aborted response because a missing parameter is dereferenced.

These steps are for vendor/CNA verification on a lab device. They are not a full exploit chain.

## Impact
An authenticated request that omits a required parameter can deny management service.
