# Stored Cross-Site Scripting via Unescaped DHCP DNS and DDNS Strings

- Published: 2026-09-14
- Supplier: Netcore
- Product: NR268
- Affected version: NR268-V1.7.121109.bin
- Vulnerability type: Stored Cross-Site Scripting (XSS)
- Contributors: Zhou Ao, Yin Luxing, Jiang Yuxuan, Liu Xin, @Nebusec

## Summary
Stored DHCP, DNS, and DDNS strings are later inserted into admin pages and parsed with eval without encoding.

## Affected Component / Code Path
- `DHCP/DNS/DDNS management pages`
- `admin UI eval() sinks`

## Technical Details
Attacker-controlled names and related strings are stored, then returned to the administrator UI and executed through eval-parsed JavaScript or HTML sinks.

## Verification
- Tested firmware: `NR268-V1.7.121109.bin`
- Authentication: Write: authenticated management user. Trigger: any administrator viewing the stored page.
- Replace `DEVICE`, `USER`, and `PASS` with a lab device and a management account.

```
# Authenticated set of a DHCP/DNS/DDNS display string, then load the admin list page that eval-parses the show response.
```

Expected result: The admin page executes the stored script in the router origin.

These steps are for vendor/CNA verification on a lab device. They are not a full exploit chain.

## Impact
A later administrator visit to the affected pages runs attacker-controlled script in the router origin.
