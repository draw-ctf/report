# Argument Injection in the Privileged DDNS Updater Command Line

- Published: 2026-09-14
- Supplier: Netcore
- Product: NR268
- Affected version: NR268-V1.7.121109.bin
- Vulnerability type: Argument Injection
- Contributors: Zhou Ao, Yin Luxing, Jiang Yuxuan, Liu Xin, @Nebusec

## Summary
DDNS provider, username, secret, and hostname fields are concatenated into updatedd/oray command lines without quoting, then tokenized on spaces.

## Affected Component / Code Path
- `/router/DDNSset.cgi`
- `DDNS updater worker`

## Technical Details
DDNSset.cgi forwards attacker-controlled fields into the DDNS worker. The worker builds command lines with sprintf and no quoting. The executor tokenizes on spaces before execvp, so a crafted field can inject extra argv entries for a root-run helper.

## Verification
- Tested firmware: `NR268-V1.7.121109.bin`
- Authentication: HTTP Basic authentication, valid management account
- Replace `DEVICE`, `USER`, and `PASS` with a lab device and a management account.

```
curl -sS -u USER:PASS -X POST -d 'hostname=example.com extra-token' http://DEVICE/router/DDNSset.cgi
```

Expected result: The updater argv includes extra tokens from the unquoted field. Confirm on a lab device.

These steps are for vendor/CNA verification on a lab device. They are not a full exploit chain.

## Impact
An authenticated admin-equivalent attacker can reshape arguments of a privileged updater.
