# Reflected Cross-Site Scripting in ntools_info_show.cgi

- Published: 2026-09-14
- Supplier: Netcore
- Product: NR268
- Affected version: NR268-V1.7.121109.bin
- Vulnerability type: Reflected Cross-Site Scripting (XSS)
- Contributors: Zhou Ao, Yin Luxing, Jiang Yuxuan, Liu Xin, @Nebusec

## Summary
The applet POST parameter is copied into the JSON-like response without escaping and the admin UI parses that response with eval.

## Affected Component / Code Path
- `/router/ntools_info_show.cgi`

## Technical Details
applet is copied with a short strncpy and emitted as a string field. The admin UI uses eval to parse the body, so a short value can break out of the string literal in the router origin.

## Verification
- Tested firmware: `NR268-V1.7.121109.bin`
- Authentication: Victim administrator browser, or an authenticated request to the show handler
- Replace `DEVICE`, `USER`, and `PASS` with a lab device and a management account.

```
curl -sS -u USER:PASS -X POST -d 'applet=test&uiname=LAN' http://DEVICE/router/ntools_info_show.cgi
```

Expected result: The applet value is reflected unescaped in the response body that the admin UI eval-parses.

These steps are for vendor/CNA verification on a lab device. They are not a full exploit chain.

## Impact
A forged request in an administrator browser can execute script in the router origin.
