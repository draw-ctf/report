# Parameter Restore Archive Bypass via Prefix Check in parame_put_file.cgi

- Published: 2026-09-14
- Supplier: Netcore
- Product: NR268
- Affected version: NR268-V1.7.121109.bin
- Vulnerability type: Security Check Bypass
- Contributors: Zhou Ao, Yin Luxing, Jiang Yuxuan, Liu Xin, @Nebusec

## Summary
Parameter restore accepts an uploaded archive when it begins with the three-byte marker .XG and then unpacks the remainder without a signature.

## Affected Component / Code Path
- `/router/parame_put_file.cgi`

## Technical Details
parame_put_file.cgi checks only the .XG prefix, strips those three bytes, and passes the remainder to the restore/unpack chain. There is no MAC or full-file integrity check.

## Verification
- Tested firmware: `NR268-V1.7.121109.bin`
- Authentication: Management authentication when the restore route is protected
- Replace `DEVICE`, `USER`, and `PASS` with a lab device and a management account.

```
curl -sS -u USER:PASS -F 'put_file=@restore.XG' http://DEVICE/router/parame_put_file.cgi
```

Expected result: A file that only starts with .XG is accepted into the restore chain. Use a lab device.

These steps are for vendor/CNA verification on a lab device. They are not a full exploit chain.

## Impact
An attacker who can reach the restore route can replace device configuration.
