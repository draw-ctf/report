# Stored Cross-Site Scripting in L7 Policy List and Detail Views

- Published: 2026-09-14
- Supplier: Netcore
- Product: NR268
- Affected version: NR268-V1.7.121109.bin
- Vulnerability type: Stored Cross-Site Scripting (XSS)
- Contributors: Zhou Ao, Yin Luxing, Jiang Yuxuan, Liu Xin, @Nebusec

## Summary
L7 policy names and related strings are stored and later executed in list and detail views through eval without encoding.

## Affected Component / Code Path
- `L7 policy set/list/detail CGI`
- `admin UI eval() sinks`

## Technical Details
Policy set handlers persist attacker-controlled strings. List and detail handlers return them to the administrator UI, which parses them with eval.

## Verification
- Tested firmware: `NR268-V1.7.121109.bin`
- Authentication: Write: authenticated management user. Trigger: administrator viewing policy pages.
- Replace `DEVICE`, `USER`, and `PASS` with a lab device and a management account.

```
# Authenticated L7 policy set with a crafted name, then load the policy list/detail show handler.
```

Expected result: The stored policy string is returned unescaped and executed by eval in the admin UI.

These steps are for vendor/CNA verification on a lab device. They are not a full exploit chain.

## Impact
Viewing the L7 policy pages runs attacker-controlled script in the router origin.
