# Netcore NR268 Stored Cross-Site Scripting in L7 Policy Pages

**Vendor:** Netcore  
**Product:** NR268 Router  
**Affected Version:** NR268-V1.7.121109.bin  
**Vulnerability Type:** Stored Cross-Site Scripting (XSS) (CWE-79)  
**Credits:** Zhou Ao, Zhang Yu, Yang Yang, Liu Xin @Nebusec

## Summary

Multiple L7 setters store group names, time-group names, URLs, keyword labels, and email strings with no metacharacter filtering beyond presence or length checks. Paired show routes emit those values with `%s`, and the web UI consumes them with `DataRequest()` / `eval('('+data+')')`. A crafted authenticated request to `/router/l7_group.cgi` can persist `group_name=<svg/onload=alert(1)>` so the user-group list renders it through `innerHTML` and executes attacker JavaScript when an administrator later opens the affected L7 pages.

## Technical Details

The L7 setters copy attacker-controlled strings into storage with only presence or length checks. Show routes serialize the stored strings with raw `%s`. The shared `DataRequest()` helper parses responses with `eval('('+data+')')`, and L7 list pages render cell content with `innerHTML`. Browser-side character checks are not enforced on the backend, so a direct authenticated POST bypasses them.

A stored `group_name=<svg/onload=alert(1)>` appears in the user-group list. Quote-bearing payloads such as `url="});alert(1);//` break out of the parsed pseudo-JSON string on the detail pages.

### Affected Endpoint

- URL: `/router/l7_group.cgi`, `/router/l7_group_show_all.cgi`, `/router/l7_group_show.cgi`, `/router/l7_app.cgi`, `/router/l7_show_app.cgi`, `/router/l7_msn_url.cgi`, `/router/l7_msn_url_show.cgi`, `/router/l7_url_key.cgi`, `/router/l7_url_key_show.cgi`, `/router/l7_mail.cgi`, `/router/l7_mail_show.cgi`, `/router/l7_grp_time.cgi`, `/router/l7_tgrp_show_all.cgi`
- Parameters: `group_name`, `url`, `name`, `email`, and related L7 label fields
- Method: POST
- Authentication: HTTP Basic authentication

## Proof of Concept

```bash
curl -s -u admin:admin -X POST "http://192.168.1.1/router/l7_group.cgi" \
  --data-urlencode "group_name=<svg/onload=alert(1)>" \
  --data-urlencode "group_info=fwprobe" \
  --data "nr=1" \
  --data "action=0" \
  --data "pri=1" \
  --data "ip0=192.168.9.9" \
  --data "mask0=192.168.9.9"

curl -s -u admin:admin -X POST "http://192.168.1.1/router/l7_group_show_all.cgi" \
  -d "noneed=noneed"
```

Open or refresh the user-group list page. `libTable.js` writes `group_name` into a table cell with `innerHTML`.

### Outcome

`l7_group_show_all.cgi` returns the unescaped `group_name`. The list page parses the response with `eval` and renders the SVG payload, executing attacker JavaScript in the administrator browser.

## Impact

- **Confidentiality:** High
- **Integrity:** High
- **Availability:** Low

A crafted authenticated request persists JavaScript that executes on L7 list and detail pages through both `eval` breakout and `innerHTML` injection.
