# Cleartext Disclosure of Stored Service Secrets in Management Responses

- Published: 2026-09-14
- Supplier: Netcore
- Product: NR268
- Affected version: NR268-V1.7.121109.bin
- Vulnerability type: Cleartext Storage of Sensitive Information
- Contributors: Zhou Ao, Yin Luxing, Jiang Yuxuan, Liu Xin, @Nebusec

## Summary
Authenticated show/export handlers return stored DDNS, PPTP, and PPPoE secrets in cleartext instead of write-only placeholders.

## Affected Component / Code Path
- `/router/ddns_wan_list_show.cgi`
- `/router/pptpd_user_show.cgi`
- `/router/pppoe_server_account_dump.cgi`

## Technical Details
The handlers serialize stored secret fields into HTTP responses. The frontend repopulates secret form fields from those values. The PPPoE dump path also exposes a downloadable account export.

## Verification
- Tested firmware: `NR268-V1.7.121109.bin`
- Authentication: HTTP Basic authentication, valid management account
- Replace `DEVICE`, `USER`, and `PASS` with a lab device and a management account.

```
curl -sS -u USER:PASS -X POST -d 'noneed=noneed' http://DEVICE/router/ddns_wan_list_show.cgi
curl -sS -u USER:PASS -X POST -d 'noneed=noneed' http://DEVICE/router/pptpd_user_show.cgi
curl -sS -u USER:PASS -X POST -d 'noneed=noneed' http://DEVICE/router/pppoe_server_account_dump.cgi
```

Expected result: HTTP 200 JSON containing cleartext secret fields.

These steps are for vendor/CNA verification on a lab device. They are not a full exploit chain.

## Impact
Anyone with a valid management session can recover reusable third-party and subscriber secrets.
